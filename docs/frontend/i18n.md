# i18n — 中英文文案

## 结构

| 路径 | 说明 |
|------|------|
| [`web/src/i18n/messages.ts`](../../web/src/i18n/messages.ts) | 中英文字典与 `translate()` |
| [`web/src/i18n/types.ts`](../../web/src/i18n/types.ts) | `Lang = "zh" \| "en"` |
| [`web/src/hooks/useAppearance.tsx`](../../web/src/hooks/useAppearance.tsx) | `t(key, vars?)`、`lang`，语言写入 `localStorage` 与 `<html lang>` |

## 用法

```tsx
const { t, lang, setLanguage } = useAppearance();
t("usage"); // 占用 / Usage
t("used", { value: "8 GB" }); // 已用 8 GB / Used 8 GB
```

覆盖范围：仪表盘、设置页、连接状态、加载文案、格式化空值（`unavailable`）、WebSocket 客户端错误键。

在设置 → 外观 → 语言中切换；立即生效并持久化。
